# 🌱 Bioinformatics Journey
Learning bioinformatics with R, focused on plant science 
and transcriptomics.

## 📁 Scripts
- `data_manipulation.R` — GEO metadata retrieval and gene 
  expression wrangling (GSE183947, tidyverse + GEOquery)

## 🛠️ Tools & Libraries
- R 4.1+
- tidyverse, dplyr, ggplot2
- GEOquery, DESeq2 (Bioconductor)

## 🎯 Goals
- Learn RNA-seq analysis pipeline
- Apply to plant science datasets
- Work toward a publication using public data
